## 2. التمييز بين الاختبار الآلي والميداني — M5.7

- **M5.7 (اكتمال العلامات قبل الإرسال النهائي):** نفّذ الخادم قاعدة رفض الإرسال النهائي الناقص، مع استثناء المؤشرات ذات الوزن صفر، والسماح بالعلامة المحصلة صفر وبترك النصوص الكتابية فارغة؛ سُجلت لها اختبارات قاعدة بيانات وواجهة في [M5.7](M5_7_MANDATORY_FINAL_MARKS_QA.md) وPR #97.
- **M5.8 (مؤشرات النقص المرئية):** ثبت ميدانيًا وضوح التمييز اللوني للعلامة الغائبة. لا يعني ذلك وحده أن المفتش أجرى في هذا التصريح محاولة إرسال **ناقصة عمدًا**، ومن ثم لا ننسب لهذا التصريح إثبات منع الإرسال الميداني تحديدًا.
- وفق سجل GitHub Actions للفرع `main` عند `d5b03a93aded158d74cc0d86e56240062ffcf015`، نجحت **453/453** اختبارات Node (صفر فشل وصفر تجاوز). هذا إثبات آلي في نطاق الاختبارات وليس اعتمادًا أمنيًا شاملًا.

## 3. ما بقي خارج نطاق هذا القبول

- استمر الفصل بين **QA** وبين Supabase الإنتاج؛ لا يُؤذن بترحيل SQL أو تفعيل حسابات اللجنة المؤقتة في الإنتاج بهذا المحضر.
- لم يُثبت هذا التصريح اختبار رفض تمديد مهمة مغلقة، أو اختبار تفويض عضو غير مالك للمهمة، أو تجاوز سقف 30 يومًا **ميدانيًا**؛ لهذه القيود تغطية في التصميم والاختبارات البرمجية السابقة ولا نخلطها مع نتائج الأجهزة.
- لا يشكل PASS شهادة بأمن RLS/Edge Function أو تقرير تدقيق اختراق.
- قبول دعوات QR/PDF هنا خاص بوثائق **الدعوة**، وليس إعادة اعتماد طباعات تقرير ومحضر الترسيم؛ القبول السابق لمخرجات الوثائق مسجل في [وثيقة قبول النموذج الأول](TITULARISATION_V1_FIELD_ACCEPTANCE_2026-11-01.md).
- لا تُحفظ أي بيانات شخصية للمترشح أو أسماء أعضاء اللجنة أو محتويات مساهماتهم أو رموز الدعوات داخل هذا المستند.
