# ARCH-01D2-P4-B17 — إزالة تكرار تاريخ الميلاد وربط تقرير الصفحة الثانية

حالة العمل: تعديل محدد؛ اعتماد إخراج المحضر السابق قائم، والمطلوب تصحيح حقول التطبيق وتقرير الصفحة الثانية فقط.

## معطيات واجهة الإدخال

- حقل واحد ظاهر باسم «تاريخ الميلاد» ويستعمل المعرّف القائم `birth`.
- حقل واحد ظاهر باسم «مكان الميلاد» ويستعمل `birthPlace`.
- لا يظهر حقل تاريخ ميلاد ثانٍ خاص بالمحضر، ولا لاحقة «(للمحضر)» في عنوان مكان الميلاد.
- يبقى المعرّف `birthDate` موجودًا داخليًا للتوافق مع ملفات JSON التي صُدرت في الإصدار B16، ولكنه غير ظاهر في الواجهة. عند تعديل حقل الميلاد الظاهر، تُحدَّث قيمة التوافق القديمة حتى لا يستعمل المحضر تاريخًا مختلفًا.

## وثائق الطباعة

- في الصفحة الثانية من التقرير، حقل «تاريخ ومكان الميلاد» يعرض تاريخ الميلاد ومكانه معًا مفصولين بفاصلة عربية؛ النص المحفوظ القديم يُستعمل عند غياب الحقول الجديدة.
- لا تعديل على الصياغة أو تنسيق أو صفحات المحضر PDF/DOCX: تبقى مقدمة المحضر، إبراز الاسم، الإمضاءات والمراجع كما قُبلت سابقًا.
- لا تغيير لموضع تذييل التقرير أو صلاحيات المفتش، أو لجان التنقيط.

## التحقق

تغطية اختبارات Node للمعلومات الظاهرة في الواجهة، تجميع حقلي التاريخ والمكان في PDF/DOCX، محفوظات JSON قديمة وحديثة، واستقرار المحضر. يعتمد القبول الطباعي النهائي على الاختبار الميداني.
