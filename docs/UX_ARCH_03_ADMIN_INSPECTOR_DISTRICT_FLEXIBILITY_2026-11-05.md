# UX-ARCH-03 — قرار معماري مُصحَّح: الإدارة مستقلة عن التفتيش

**05/11/2026. الحالة: تصميم وتنفيذ SQL مقترح فقط؛ غير منشور، وغير مطبَّق على قاعدة الإنتاج أو QA.**

## القرار الملزم

- حساب `Admin` مخصّص لإدارة المنصة وصيانتها. لا يشترط ربطه بمقاطعة عمل، ولا يدخل تلقائيًا في دليل المفتشين أو مهامهم المهنية.
- حساب المفتش مستقل ومخصص للتحضير والتفتيش والتقارير والبيانات الخاصة. يعرض افتراضيًا زملاء مقاطعة عمله والمؤسسات المنشورة له.
- لصاحب الموقع اختيار **أي رمز نصي فريد وغير فارغ** للمقاطعة، مثل `12` أو `12-01` أو `12-أ`، وتعديل الرمز أو الاسم لاحقًا دون تغيير المعرّف الداخلي الثابت UUID أو إعادة إسناد المفتشين. لا يعامل النظام رمز المقاطعة باعتباره رمز الولاية.
- للـ`Admin` إنشاء المؤسسات مباشرة أو قبول اقتراحات المفتشين، وإسناد **مؤسسة واحدة إلى عدة مقاطعات** باستخدام جدول علاقات متعدد إلى متعدد؛ لا يجري نسخ سجل المؤسسة أو تقسيمه إلى نسخ متفاوتة.
- يجوز للمسؤول نشر مؤسسة ضمن أي مقاطعة يختارها، سواء كانت داخل ولاية موقع المؤسسة أم خارجها. التصنيف الإداري اختيار صاحب الموقع وليس استنتاجًا جغرافيًا.
- تظل البيانات الشخصية للمفتش خاصة. يستهدف النشر سجل المؤسسة المهني فقط. الوصول إلى مؤسسة منشورة لا يكشف بيانات الملاحظات الشخصية.
- صلاحية `Admin` واسعة في إدارة الأسماء والرموز والتوزيع، مع إبقاء سجل تغييرات وحماية عمليات قاعدة البيانات من حسابات المفتشين أو الحسابات غير الموثقة.

## بيانات حيّة يجب المحافظة عليها

عند الجرد كانت توجد مقاطعتان محفوظتان بالفعل: `09-00` باسم «البليدة» و`12-00` باسم «تبسة»، مع تحضير محفوظ وسجل خاص وطلب نشر واحد. يُعدل المسؤول `12-00` إلى `12` من **المقاطعة نفسها** ولا ينشئ سجلًا مكررًا. ولا تُعدّل هذه السجلات تلقائيًا.

## مسار التنفيذ

1. اختبار الترحيل SQL المقترح في QA دون تغيير المستخدمين الحقيقيين، ومراجعة امتيازات المسؤول والإدراج في عدة مقاطعات.
2. إنشاء واجهة إدارة منفصلة: تغيير رموز المقاطعات وأسمائها، وإدارة علاقات المؤسسة بالمقاطعات، واستيراد المؤسسات القائمة اختياريًا مع الاحتفاظ بأصولها.
3. التحقق من أن حساب `Admin` لا يحتاج مقاطعة عمل وأن أدوات المفتش غير معروضة عليه؛ وبالمقابل لا تظهر أدوات الإدارة لحساب المفتش.
4. اختبارات صلاحيات RLS وRPC باستخدام أدوار منفصلة، ثم نشر تدريجي بعد مراجعة أثر الترحيل.

**لا يُعلن هذا التطوير مكتملًا حتى تنجح الاختبارات ويُطبَّق على QA والإنتاج ويُنشر محرر الإدارة.**
