# ARCH-01D1 — مختبر تجريبي مستقل لتنقيط الترسيم

> بحث تقني غير رسمي وغير مرتبط بقاعدة Supabase. لا يتعامل مع أسماء مترشحين أو أعضاء لجنة حقيقيين، ولا يُصدر تقريرًا أو محضرًا معتمدًا، ولا يُضاف إلى لوحة المهمات الحية للنموذج 03.

## تجربة الاستخدام

افتح [واجهة المختبر](index.html) من GitHub Pages عند مسار prototypes/titularisation-workbench/، أو عبر خادم HTTP محلي. يعتمد المختبر وحدات JavaScript مستقلة.

- اختيار إحدى **ثلاث شبكات مستقلة**. تغيير الشبكة يبدأ مسودة فارغة دون نقل أي درجات أو أوزان.
- شبكة 5 معايير وأوزان المجموعات 12 / 8 / 8 / 6 / 6؛ أصلها استعمال تاريخي دون اعتماد رسمي. **تظهر المؤشرات الأربعة عشر التابعة لها موزعة تحت عناوين المعايير الخمسة للتذكير، دون حقول تنقيط إضافية.**
- شبكة 10 عناصر وأوزانها 5 / 4 / 4 / 5 / 5 / 5 / 4 / 2 / 2 / 4؛ أصلها اجتهاد مفتش من تجربة رافور، دون اعتماد رسمي.
- شبكة 14 مؤشرًا مستمدة من نص PDF، تحت خمسة معايير، بأوزان قابلة للتعديل في **المسودة الحالية** تبدأ من صفر وتزداد بمقدار 0.5؛ مجموع أوزان كل مجموعة يجب أن يساوي سقفها تمامًا.
- توزيع إرشادي لا يعمل إلا عند الطلب؛ تثبيت الأوزان قبل إدخال علامات المؤشرات؛ لا تعديل بعد التثبيت.
- تنقيط الحصة والمناقشة **في الشبكات الثلاث بخطوة 0.5 نقطة مع السماح بالعلامة صفر**، وحساب نتائج اختبارية على /40 و/20 و/60؛ إظهار القسمة على 3 **دون إعلان تقريب رسمي** أو اتخاذ قرار اللجنة.
- **ARCH-01D1.2:** لكل علامة قابلة للتنقيط **حقل رقمي وشريط تمرير متزامنان فورًا في الاتجاهين**. التدريج ظاهر من 0 إلى سقف العنصر مع نقطة المنتصف، وخطوة الشريط 0.5. لا يُسجل الصفر عند مجرد فتح صفحة فارغة، وعند مسح الحقل تعود الحالة إلى «لم تُسجّل علامة بعد». المؤشر ذو الوزن صفر **لا يحصل على شريط تنقيط**.
- **ARCH-01D1.3 — حماية التمرير باللمس:** أكّد المستخدم نجاح الشريط على الهاتف والحاسوب، لكنه لاحظ أن تمرير الصفحة على الهاتف بإصبع اليد اليسرى قد يغير علامة عند لمس المسار. **على الأجهزة اللمسية، جميع الأشرطة محمية أثناء التمرير افتراضيًا**؛ تضغط زر **«تفعيل الشريط للتنقيط»** عند المؤشر المطلوب لفتح **ذلك الشريط وحده**، ثم تختار النقطة ويُقفل تلقائيًا. مجرد الضغط على زر التفعيل لا يضع علامة، والقفل لا يمنع إدخال الرقم مباشرة، ويُستعاد أيضًا عند تمرير الصفحة. أجهزة الحاسوب دون واجهة لمس تحتفظ بأشرطة تعمل مباشرة دون أزرار إضافية.
- المؤشر ذو الوزن صفر يبقى مرئيًا ويعرض «غير منقّط»، دون إدخال درجة صفر باسمه. العلامة صفر المدخلة لمؤشر آخر تختلف عن العلامة الفارغة.
- تصدير واستيراد مسودة JSON محلية مع اختبار هوية الشبكة وصحة الأوزان والدرجات.

## حدود المرحلة

بعد تجربة المستخدم صححنا **خطوة العلامات المحصلة إلى 0.5 في جميع شبكات الحصة والمناقشة**؛ تُرفض كسور مثل 1.25 عند الإدخال أو الاستيراد، وتبقى العلامة صفر صحيحة. **سياسة تقريب العلامة المعروضة على /20** ما زالت بحاجة لقرار مستقل. لا تتضمن هذه النسخة مرشحًا فعليًا أو أعضاء لجنة أو تقييمات فردية موثقة أو توقيعًا أو تقرير PDF أو محضر DOCX أو مسطرة اعتماد.

لا يستعمل المختبر حسابات المستخدمين ولا قاعدة Supabase ولا مخزن بيانات دائمًا في المتصفح. لا ترسل الشيفرة نفسها محتوى النموذج إلى الخادم. **يُمنع إدخال بيانات شخصية حقيقية في هذه التجربة** أو نشر ملفات JSON التي تتضمنها.
