# Official Report Template 03 — النسخة التنفيذية الأولى

محرّر عربي (RTL) لتقرير **التفتيش المعمق / النموذج 03** بمرجع بصري `Official_report_template_03.pdf`.

## النطاق المنفذ
- إدخال بيانات المهمة والمؤسسة ورئيسها والمفتشين المشاركين في الغلاف.
- فهرس 11 باباً و39 مجالاً (38 مجالاً من الأبواب II–VIII، ومجالًا عاماً إضافياً للباب IX)، مع 155 عنصراً مرشحاً (149 مستخرجاً من DOCX + 6 في الباب IX).
- معاينات وتوصيات متعددة لكل مجال/عنصر، مع تصنيف اختياري مستقل: مطابق / غير مطابق / غير معني / لم يُقيّم بعد. تحفظ الحالات في JSON وتظهر في DOCX وPDF عند تحديدها، دون إضافة أعمدة جديدة للنموذج الرسمي أو توليد أحكام تلقائية.
- استخراج **JSON حقيقي** وإعادة استيراده، و**DOCX قابل للتحرير** يُولد في المتصفح دون مكتبات خارجية، و**PDF من نافذة طباعة المتصفح** (اختر: حفظ بتنسيق PDF).
- لا قاعدة بيانات ولا تسجيل دخول ولا تسجيلات تحليلية ولا تخزين محلي تلقائي: الحالة داخل ذاكرة التبويب فقط؛ ويمكن مسحها فورًا. أغلق التبويب فتنتهي الحالة. ينبغي تصدير JSON قبل الإغلاق لاستئناف العمل.

## قيود يجب عدم إخفائها
- **هذا الإصدار تجريبي وغير معتمد لإصدار وثائق نهائية.** الفهرس مستخرج بصورة أولية من DOCX ولم يُدقق عنصرًا عنصرًا أمام PDF. عدد المؤشرات ليس حصرًا نهائيًا. يمنع وصف المطابقة البصرية بأنها 100% قبل اجتياز اختبارات المقارنة.
- تصدير PDF يتم عبر `window.print()` وحوار الطباعة، لا بتنزيل ملف PDF مباشر. يتأثر توزيع الصفحات والخطوط بمحرك الطباعة لدى المستخدم.
- DOCX مُنتج من الصفر بتقريب رسمي قابل للتحرير، ولم يُتحقق بعد من التطابق البصري الكامل مع PDF.
- ورود أسماء عدة مفتشين في الغلاف **لا يعني تفعيل حساباتهم أو تعاونهم الفعلي**. ميزة الفريق المتساوي واقتراحات أحد المفتشين في مجال الآخر تستلزم Backend آمنًا، وستضاف في مرحلة مستقلة؛ لا نحتفظ بالتقارير المنجزة طويلًا، ويمكن بناء جلسات مؤقتة تحذف عند الانتهاء.
- «اعتماد» التقرير وتوقيعات المفتشين غير مطبقين. المخرجات معلّمة كمسودات.

## التشغيل

```
python3 -m http.server 8000
```

افتح `http://localhost:8000`. لا حاجة إلى أي مفاتيح أو حسابات لتجربة المحرر.

## الاختبار والنشر

تحقق سريع: `node --check app.js` و`python3 -m json.tool catalog.json >/dev/null`. للنشر العام افتح Settings → Pages → Build and deployment → Source واختر `GitHub Actions`. بعد التفعيل شغّل مسار `Deploy Official Report 03 (static)` من Actions، أو ادفع تغييرًا إلى الفرع `main`. سيتم نشر موقع ثابت بلا خادم خلفي.

## سياسة الاحتفاظ بالبيانات

الافتراضي **عدم حفظ أي تقرير منجز في خادم**، وعدم استعمال `localStorage` أو IndexedDB. يجب تنبيه المستخدم عند مسح البيانات وتوفير التصدير بصيغ JSON وDOCX وPDF. عند تطوير العمل المشترك مستقبلًا يجب تخزين المسودات النشطة تخزينًا مؤقتًا مشفرًا بضوابط وصول، ثم حذفها وفق سياسة معلنة دون ادعاء ضمان محو النسخ الاحتياطية فورًا.
